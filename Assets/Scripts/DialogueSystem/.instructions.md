# DialogueSystem 开发注意事项

## MVP 架构
- **Model**（`DialogueModel`）：纯数据层，不继承 MonoBehaviour，只做 Yarn 适配器的代理
- **Presenter**（`DialoguePresenter`）：MonoBehaviour 调度层，接收 Model 事件并驱动 View
- **View**（`DialogueUIController`）：被动视图，只暴露 `SetText`/`ShowOptions` 等接口，不包含"下一步干什么"的逻辑
- **Adapter**（`YarnDialogueAdapter`）：继承 `DialogueViewBase`，将 Yarn 数据转为 `DialogueNode`

## 组件绑定
- Presenter 与 View 的绑定用 `Awake + GetComponent`，**不要用 SerializeField 拖拽**（容易漏拖/拖错）
- 如果挂同一个 GameObject 上找不到，用 `FindFirstObjectByType<T>(FindObjectsInactive.Include)` 兜底

## 与 Yarn 的交互
- View 不直接接触 Yarn API，所有 Yarn 操作通过 Adapter
- Presenter 下达 `SelectOption` 等指令时，通过 Model 传递给 Adapter → Yarn
