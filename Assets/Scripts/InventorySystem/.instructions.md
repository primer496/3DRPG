# InventorySystem 开发注意事项

## 分层
- **Model**：纯 C# 数据类（`InventoryModel`、`InventorySlot`），不继承 MonoBehaviour
- **ViewModel**：MonoBehaviour 桥接层（`InventoryViewModel`），订阅 Model 变化 + EventBus
- **View**：MonoBehaviour 挂 UI 上（`InventoryUIController`），只负责显示，不包含业务逻辑
- **Utils**：工具类（`ItemIconLoader`），纯逻辑

## 数据
- 道具配置用 `ItemData` ScriptableObject，放在 `Resources/GameConfigs/PackageModel/`
- 文件名 = `ItemData_<名称>.asset`
- Yarn 对话里引用的 item ID 必须和 SO 文件名一致

## 通信
- 通过 `EventBus.Instance.OnItemRewarded` 接收物品奖励
- 在 `OnDisable` 里取消所有 EventBus 订阅

## UI
- 用 UI Toolkit（`UIDocument` + `VisualElement`），不用 uGUI
