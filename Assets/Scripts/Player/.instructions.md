# Player 开发注意事项

## 属性系统
- `PlayerStats` 是纯 C# 数据类（不继承 MonoBehaviour），包含 HP/Exp/Gold/Level
- `PlayerStatsProvider` 是 MonoBehaviour 桥接层，挂 Player 根对象上
- 外部通过 `PlayerStatsProvider.Stats` 获取数据实例并绑定事件
- Provider 在 `OnEnable`/`OnDisable` 中订阅/取消 EventBus 事件

## HUD
- `PlayerHUDController` 用 UI Toolkit（`UIDocument` + `VisualElement`）
- UI 元素查询：`_root.Q<ProgressBar>("hp-bar")` 模式，务必判空
- 通过 `EventBus.Instance.OnInputLockStateChanged` 控制 HUD 显示/隐藏
- `LateUpdate` 兜底 ApplyVisibility，消除同帧事件顺序导致的偶发闪烁

## 事件绑定模式
```csharp
private void OnEnable()
{
    _stats.OnHPChanged += RefreshHP;
    EventBus.Instance.OnGoldRewarded += AddGold;
}
private void OnDisable()
{
    _stats.OnHPChanged -= RefreshHP;
    EventBus.Instance.OnGoldRewarded -= AddGold;
    _stats = null;
}
```
