# QuestSystem 开发注意事项

## 数据
- 任务配置用 `QuestData` ScriptableObject（`CreateAssetMenu: "Quest System/Quest Data"`）
- 每个 QuestData 的 `id` 字段是全局唯一标识

## 与 Yarn 同步
- Yarn 里的任务完成/接受状态必须与 `QuestViewModel` 同步
- 在 Yarn 结束节点同时设置 `QuestCompleted`/`QuestAccepted` 并调用 `CompleteQuest`
- 不要在 Yarn 里只设变量不调 API，会导致状态不一致

## 通信
- QuestManager 通过 `EventBus` 广播任务进度，不直接操作 UI
- NPC 交互走 `NPCInteractable`（`QuestSystem.Interaction` 命名空间）

## UI
- `QuestUIController`（View）只负责显示，逻辑在 `QuestViewModel` 里
