# HSM 开发注意事项

## 状态机规则
- 新状态必须继承 `PlayerRoot` → `Grounded` 或 `Airborne` 之一
- 不要在 `State.Update()` / `State.GetTransition()` 里写 `await`
- 状态切换动画走 `TransitionSequencer`（Phase/Step 模型），不要直接在 State 里调 Animator API

## 动画分工
- 动画过渡由 Animator 自己管理（Transition 条件），HSM 只轮询状态名
- 用 `GetCurrentAnimatorStateInfo(0).IsName("")` 做同步，不要从代码强切 Animator 状态

## 移动 & 物理
- 接地检测用多帧平滑，不要单帧射线（坡道边缘会闪断）
- 斜坡移动方向沿坡面切线，不能用世界 XZ 平面投影
- Y 轴位移只在一处管理，不要代码 + 物理双重注入

## 配置
- 角色参数用 ScriptableObject（`ActorMovementConfig`、`ActorCombatConfig` 等）
- 通过 `PlayerCapabilityConfigSet` / `EnemyCapabilityConfigSet` 组装并挂到 `PlayerStateDriver`
